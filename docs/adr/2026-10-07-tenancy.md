# Tenancy

## Context

The orchestrator runs Claude Code agents unattended on cloud VPSes and on
the owner's laptop, with one place to command them, watch them live, and
keep what they produce. Only the owner runs the server and the client
machines.

Supporting several users requires authentication and tenancy work, which
would otherwise come before the parts that run, command, and watch agents
exist.

## Decision

The orchestrator serves a single user. Multi-user collaboration is
deferred.

## Consequences

- The harness bills against the owner's Claude subscription
  ([harness billing](2026-10-07-harness-billing.md)).
  **UNVERIFIED:** a single-owner setup appears to be within the consumer
  terms (https://www.anthropic.com/legal/consumer-terms); collaborators
  would each need their own token.
